# 🔍 Reverse Engineering Mastery — Complete Course (Hinglish)

Zero se lekar Mobile RE tak — Reverse Engineering seekhne ka **complete, structured course** simple **Hinglish** mein, examples aur code ki line-by-line explanation ke saath.

> Har concept aasan tone mein samjhaaya gaya hai, aur har phase ke saath **interview Q&A (Hinglish + English)** aur ek **professional PDF handbook** diya gaya hai.

---

## 📚 Course Structure (8 Phases)

| # | Phase | Kya seekhoge |
|---|-------|--------------|
| 0 | [Foundation](Phase-0-Foundation) | Number systems, memory, C basics, compilation |
| 1 | [Assembly Language](Phase-1-Assembly-Language) | Registers, instructions, stack, function calls |
| 2 | [Tools](Phase-2-Tools) | Ghidra, x64dbg aur helper tools |
| 3 | [Static Analysis](Phase-3-Static-Analysis) | Bina chalaaye code padh ke samajhna |
| 4 | [Dynamic Analysis](Phase-4-Dynamic-Analysis) | Breakpoints, live values, patching |
| 5 | [Real Practice](Phase-5-Real-Practice) | Crackmes, CTF, malware analysis, VM lab |
| 6 | [Specialization](Phase-6-Specialization) | Malware, exploits, mobile, crypto, firmware |
| 7 | [Mobile RE](Phase-7-Mobile-RE) | Android (APK, smali) + iOS (IPA) |

---

## 📂 Har Phase Folder Mein Kya Hai

Har phase folder mein **4 files** hain:

- **`Notes.md`** — Detailed Hinglish notes, examples aur code ki line-by-line explanation ke saath.
- **`Interview-QA-Hinglish.md`** — Important theory questions + answers (Hinglish) — bolne ke liye.
- **`Interview-QA-English.md`** — Wahi questions English mein — interview mein exact answer dene ke liye.
- **`Phase-X-*.pdf`** — Us phase ki poori details, professional PDF handbook (Notes + dono Q&A).

## 🎯 Kaise Use Karein

1. **Phase 0 se shuru karo** — neev majboot karo.
2. Har phase ka `Notes.md` padho, phir PDF se revise karo.
3. Interview se pehle dono **Q&A files** dekho.
4. **Phase 5** se practice (crackmes, CTF) shuru karo aur continue rakho.
5. Ek-ek phase complete karke aage badho — jaldbaazi nahi.

## ⚠️ Legal Note

Reverse Engineering sirf **authorized testing, learning, CTF challenges, apne khud ke software, ya practice programs** pe karo. Kisi ki software/protection bina permission ke todna illegal hai. Malware hamesha **isolated Virtual Machine** mein analyze karo.
